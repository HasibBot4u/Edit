> - Every FR, SCR, DATA, API, SEC, and TEST link below is semantically grounded in its source specification — never inferred from numeric adjacency.
> - **Primary ownership** vs **Shared / Secondary** reuse is explicitly labeled where features intersect (e.g., `FEAT-13` vs `FEAT-14` on `FR-045..046` / `TEST-087..088`; `FEAT-15` vs `FEAT-08` on `TEST-045..046`).

> - Zero existing IDs are renumbered; zero missing feature FRs or tests are fabricated (`OPEN` where under-specified; `NOT TESTED` for all execution states).
